LeanLog v1 - free offline-capable personal food logger

Launch locally by opening index.html in a browser. For the installable iPhone experience:
1. Upload the contents of this folder to any HTTPS static host (e.g. GitHub Pages).
2. Open the hosted URL in Safari on iPhone.
3. Tap Share > Add to Home Screen.

IMPORTANT:
- Everything is stored locally in the browser (localStorage), not in a cloud account.
- You can export/import a JSON backup under Settings. Back up regularly.
- Ingredient nutrition is approximate; amounts and cooked/raw differences need your review.
- No AI API, barcode scanner, MacroFactor syncing or cross-device syncing is included.
- Unknown foods need manual nutrition inputs. Food parser works best with comma-separated grams.
